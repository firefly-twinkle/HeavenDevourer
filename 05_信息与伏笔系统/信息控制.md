# 信息控制

> 控制信息释放节奏，制造悬念和期待感

---

## 核心原则

1. **禁止一次性解释全部设定** - 信息必须分阶段释放
2. **制造未知与悬念** - 读者知道的部分 < 世界实际存在的部分
3. **信息释放必须有代价** - 重要信息通过剧情推进获得

## 悬念制造技巧

### 1. 信息差

```
读者知道 > 角色知道 = 紧张感
读者知道 < 角色知道 = 好奇心
```

### 2. 部分揭露

```
揭露 30% → 读者好奇 → 揭露 60% → 读者期待 → 揭露 100% → 爽感
```

### 3. 误导后反转

```
建立预期 → 强化预期 → 突然反转 → 真相揭露
```
