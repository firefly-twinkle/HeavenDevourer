## 功法详细设定

### 吞天诀（帝阶·完整）

**来源**：传承之地第一层，吞噬大帝传承

**效果**：
- 吞噬敌人修为/血脉/功法
- 无冷却时间，无上限
- 可调和任何属性功法冲突
- 完整版解锁吞噬天地等高级能力

**封印状态**：
- 当前解封：完整版（已通过传承之地考验）
- 完全解封：武帝境

**熟练度进度**：
```
初学 → 入门 → 小成 → 大成 → 圆满 → 化境
                              ↑
                          当前状态
```

### 青云诀（黄阶上品）

**来源**：林家祖传

**效果**：
- 基础修炼功法
- 灵气运转速度 +30%

**熟练度进度**：
```
初学 → 入门 → 小成 → 大成 → 圆满 → 化境
                                      ↑
                                  当前状态
```

**效果**：
- 将吞噬领域与火焰之力压缩成一道暗金色光柱
- 兼具吞噬一切的霸道与焚烧万物的狂暴
- 消耗极大，以武灵境巅峰修为只能释放有限次数

- 修为未达武王境，无法完全发挥威力

**熟练度进度**：
```

    ↑
当前状态（初成）
```
