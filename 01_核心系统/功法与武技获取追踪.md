## 功法详细设定

### 吞天诀（帝阶·封印中）

**来源**：系统觉醒

**效果**：
- 吞噬敌人修为/血脉/功法
- 无冷却时间，无上限
- 可调和任何属性功法冲突

**封印状态**：
- 当前解封：第一层（基础吞噬）
- 下一层解封条件：武王 5 星
- 完全解封：武帝境

**熟练度进度**：
```
初学 → 入门 → 小成 → 大成 → 圆满 → 化境
                            ↑
                        当前状态
```
