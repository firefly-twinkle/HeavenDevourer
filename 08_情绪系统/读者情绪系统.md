# 读者情绪系统

> 设计和控制读者情绪起伏，创造最佳阅读体验

---

## 情绪类型定义

| 情绪 | 说明 | 触发场景 |
|------|------|----------|
| 爽 | 主角反击/碾压 | 反杀、突破、震惊全场 |
| 紧张 | 主角面临危险 | 被追杀、绝境、时间压力 |
| 压迫 | 强敌出现/局势恶化 | 强敌降临、阴谋揭露 |
| 好奇 | 未知信息/悬念 | 秘密揭露前、新角色登场 |
| 愤怒 | 不公/背叛 | 亲友受害、被陷害 |
| 感动 | 牺牲/守护 | 盟友牺牲、女主深情 |
| 期待 | 未来目标/约定 | 复仇预告、突破在即 |

---

## 情绪曲线设计

### 单章情绪结构

```
开场（平淡）→ 冲突（紧张）→ 行动（期待）→ 结果（爽）→ 悬念（好奇）
```

### 多章情绪循环

```
轻（过渡）→ 压（冲突）→ 爽（反击）→ 爆（高潮）→ 缓（消化）
     1-2 章      1-2 章     1-2 章     1 章      1 章
```

**循环周期**：3-5 章完成一个完整情绪循环

## 第 1 卷 情绪曲线（第 1-25 章）

| 章节范围 | 主情绪 | 次情绪 | 关键事件 |
|----------|--------|--------|----------|
| 第 1-2 章 | 压抑→爽 | 紧张 | 穿越反杀，系统觉醒 |
| 第 3-5 章 | 紧张 | 期待 | 逃亡、成长、突破 |
| 第 6-10 章 | 爽 | 兴奋 | 狩猎妖兽、连胜突破 |
| 第 11-15 章 | 兴奋 | 期待 | 返回青阳、拍卖会、擂台 |

| 第 22-25 章 | 紧张→危机 | 震惊 | 身份暴露、夺得令牌逃脱 |

## 情绪设计技巧

### 1. 欲扬先抑

```
压抑（被轻视/被追杀）→ 爆发（反击/碾压）= 爽感最大化
```

**示例**：
- 第 1 章：穿越成废柴→反杀天才
- 第 18 章：被质疑→十连胜打脸

### 2. 情绪叠加

```
小爽点 + 中爽点 + 大爽点 = 爆点
```

**示例**：
- 第 18 章：连胜（小爽）+ 突破（中爽）+ 十连胜第一人（大爽）= 卷内爆点

### 3. 情绪对比

```
极度压抑后爆发 > 普通爆发
极度危险后安全 > 普通安全
```

**示例**：
- 第 25 章：被围剿（极度危险）→ 逃脱（松一口气）

### 4. 情绪延续

```
本章悬念 → 下章解答 = 读者持续追更
```

## 情绪密度检查

### 检查规则

| 规则 | 标准 | 检查方式 |
|------|------|----------|
| 情绪变化 | 每章至少 1 次情绪变化 | 检查本章情绪曲线 |
| 情绪重复 | 禁止连续 3 章同主情绪 | 检查近 3 章主情绪 |
| 情绪起伏 | 必须有起伏，不能一直平 | 检查情绪曲线图 |
| 高潮间隔 | 每 5 章至少 1 次情绪高潮 | 检查近 5 章 |

### 检查模板

```
第 X 章 情绪检查：
- 开场情绪：___
- 中段情绪：___
- 结尾情绪：___
- 情绪变化：___次
- 主情绪类型：___
- 与上一章重复：☐ 是 ☐ 否
```

## 负面情绪处理

### 常见负面情绪

| 情绪 | 触发原因 | 处理方式 |
|------|----------|----------|
| 憋屈 | 主角被压制太久 | 3 章内必须反击 |
| 失望 | 爽点不足/推进慢 | 增加爽点密度 |
| 困惑 | 信息不足/设定冲突 | 补充说明/统一设定 |
| 愤怒 | 角色降智/不公 | 修正角色行为逻辑 |

### 毒点规避

| 毒点类型 | 说明 | 规避方式 |
|----------|------|----------|
| 送女 | 女主与配角暧昧 | 女主只与主角有感情线 |
| 绿帽 | 女主被玷污 | 绝对禁止 |
| 憋屈 | 主角一直被压 | 压抑≤3 章必须释放 |
| 降智 | 角色行为不合逻辑 | 行为符合动机和智商 |
| 圣母 | 主角无底线原谅 | 主角杀伐果断 |
