# 封面设计需求文档

---

## 一、基本信息

| 项目   | 要求             |
| ---- | -------------- |
| 书名   | 《从吞噬开始无敌》      |
| 作者名  | 一念格物           |

| 格式   | JPG/PNG，RGB 色彩 |

## 二、设计理念

### 核心概念
**"吞噬" + "无敌"**

- **吞噬**：黑暗、深渊、漩涡、吸收一切
- **无敌**：金色、光芒、帝者、俯瞰众生

### 视觉关键词
```
黑暗、漩涡、金色、破碎、燃烧、武帝、霸氣
```

---

## 三、画面元素

### 方案 A：人物主体版

```
构图：
- 前景：青年男子背影/侧脸（主角林夜）
- 中景：黑色吞噬漩涡（视觉中心）
- 背景：破碎的家族徽章/燃烧的废墟
- 特效：金色气息缠绕全身

人物特征：
- 年龄：18-20 岁
- 发型：黑色长发（随风飘动）
- 服装：黑色长袍（带金色纹路）
- 眼神：坚定、冷冽（如露侧脸）
- 姿态：站立/俯瞰

色彩：
- 主色：黑色 60% + 暗红 20% + 金色 20%
- 人物：黑色长袍 + 金色轮廓光
- 背景：暗红/橙红（燃烧感）
```

### 方案 B：意象版

```
构图：
- 中心：巨大黑色漩涡（吞噬意象）
- 漩涡中心：一道金色人影
- 周围：破碎的兵器/骨骼/符文
- 上方：书名大字

色彩：
- 主色：纯黑 70% + 暗红 15% + 金色 15%
- 漩涡：黑色渐变到深紫
- 金光：从中心向外辐射
```

### 方案 C：简约文字版

```
构图：
- 背景：纯黑渐变
- 中央：书名大字（书法体）
- 文字特效：金色描边 + 黑色漩涡纹理
- 底部：作者名 + 小图标

适合：快速上线/测试用
```

## 四、字体要求

### 书名用字
| 项目 | 要求 |
|------|------|
| 字体 | 书法体/粗体（有力量感） |
| 推荐 | 汉仪尚巍手书、方正榜书、华文行楷 |
| 颜色 | 金色（#FFD700）+ 黑色描边 |
| 大小 | 占画面高度 1/4 |
| 排列 | 横排或竖排均可 |

### 作者名用字
| 项目 | 要求 |
|------|------|
| 字体 | 简洁黑体/宋体 |
| 颜色 | 白色/浅金色 |
| 大小 | 书名 1/3 大小 |
| 位置 | 封面底部 |

## 五、色彩规范

### 主色调
```
黑色：#0A0A0A（背景/漩涡）
暗红：#8B0000（燃烧/血色）
金色：#FFD700（文字/光效）
```

### 辅助色
```
深紫：#2D1B4E（漩涡渐变）
橙红：#FF4500（火焰）
银白：#C0C0C0（高光）
```

### 色彩比例
- 黑色系：60%（主背景）
- 暗红/橙红：20%（氛围）
- 金色：15%（文字 + 光效）
- 其他：5%（点缀）

## 六、参考封面

### 风格参考 1：《斗破苍穹》
- 人物居中，背后是异火/能量
- 暗色调 + 彩色能量对比
- 书法字标题

### 风格参考 2：《吞噬星空》
- 科幻 + 玄幻结合
- 星空背景 + 人物剪影
- 金色/蓝色主色调

### 风格参考 3：《完美世界》
- 人物霸气侧漏
- 背景宏大（废墟/战场）
- 金色 + 暗红配色

---

## 七、避免元素

❌ 不要用：
- 可爱/Q 版风格
- 明亮小清新色调
- 过于复杂的人物正面（容易崩）
- 英文字符（除格式要求外）
- 水印/二维码
