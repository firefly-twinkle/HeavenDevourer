# 连载调度规则

---

## 更新频率管理

### 标准更新节奏

| 更新模式 | 频率 | 适用场景 | 章节产出 |
|----------|------|----------|----------|
| 日更 | 每天 1 章 | 正常连载期 | 7 章/周 |
| 双更 | 每天 2 章 | 推荐位/爆更期 | 14 章/周 |
| 爆更 | 每天 3-5 章 | 重要节点/活动 | 21-35 章/周 |
| 存稿 | 不定期 | 积累缓冲 | 灵活 |

### 推荐更新策略

**建议采用：日更为主，节点爆更**

- 日常：每天 1 章（保持曝光）
- 周末：每天 2 章（周末流量高峰）
- 重要节点：爆更 3-5 章（新书榜/推荐位）
- 存稿缓冲：始终保持 5-10 章存稿

## 章节发布时机

### 最佳发布时间

| 时间段 | 时间 | 效果 | 说明 |
|--------|------|------|------|
| 早晨 | 7:00-9:00 | 中 | 通勤时间，阅读量中等 |
| 中午 | 12:00-14:00 | 中 | 午休时间，阅读量中等 |
| 傍晚 | 17:00-19:00 | 中 | 下班通勤，阅读量中等 |
| 晚上 | 20:00-22:00 | 高 | 黄金时间，阅读量最高 |
| 深夜 | 22:00-24:00 | 高 | 夜猫子用户，阅读量高 |

### 推荐发布时间

**固定时间：晚上 20:00**

- 培养读者阅读习惯
- 覆盖黄金阅读时段
- 便于第二天早上查看数据反馈

## 剧情节奏与更新配合

### 爽点分布

| 章节间隔 | 爽点类型 | 更新配合 |
|----------|----------|----------|
| 每章 | 小爽点 | 保持日常更新 |
| 每 3-5 章 | 中爽点 | 周三/周五发布 |
| 每 10 章 | 大爽点 | 周末爆更 |
| 每卷 | 卷末爆点 | 重要节点爆更 |

### 卡点策略

**在关键节点卡章，引导读者追更**

- 战斗高潮前卡章（"下一秒，刀锋已到！"）
- 真相揭露前卡章（"他缓缓说出三个字..."）
- 突破关键时刻卡章（"灵力开始暴走！"）
- 新角色登场卡章（"门外走来一个熟悉的身影"）

## 存稿管理

### 存稿水位线

| 水位线 | 章节数 | 操作策略 |
|--------|--------|----------|
| 安全线 | 10 章 + | 可正常更新，可小幅爆更 |
| 警戒线 | 5-10 章 | 减少爆更，积累存稿 |
| 危险线 | 3-5 章 | 停止爆更，全力存稿 |
| 红线 | 0-3 章 | 考虑请假或 reduced 更新 |

### 存稿使用策略

1. **日常更新**：用新写章节，存稿不动
2. **紧急补更**：从存稿提取，事后补回
3. **爆更活动**：使用 30% 存稿，保留 70%
4. **请假替补**：使用存稿顶替，不中断更新

## 读者互动管理

### 评论区运营

| 操作 | 频率 | 说明 |
|------|------|------|
| 回复热评 | 每章后 | 挑选 3-5 条热评回复 |
| 作者说 | 每章 | 章末/章后加作者说 |
| 互动活动 | 每周 | 剧情讨论/角色命名等 |
| 问题解答 | 不定期 | 解答读者疑问 |

### 作者说模板

```
【作者说】
- 本章亮点：[一句话概括]
- 剧情预告：[下一章看点]
- 互动话题：[引导讨论]
- 求支持：[推荐/收藏/评论]
```

## 数据监控

### 核心指标

| 指标 | 监控频率 | 健康值 | 说明 |
|------|----------|--------|------|
| 收藏数 | 每日 | 持续增长 | 书籍总收藏 |
| 阅读量 | 每章 | 稳定/增长 | 单章阅读 |
| 评论数 | 每章 | 10+ | 读者互动 |
| 推荐票 | 每日 | 持续增长 | 读者投票 |
| 追读率 | 每周 | 30%+ | 追更读者比例 |

### 数据异常处理

| 情况 | 表现 | 应对策略 |
|------|------|----------|
| 阅读量下跌 | 连续 3 章下跌 | 检查剧情是否毒点 |
| 评论减少 | 互动降低 | 增加互动话题/爆点 |
| 收藏增长停滞 | 新增收藏少 | 检查推荐位/封面/简介 |
| 追读率下降 | 老读者流失 | 检查剧情是否劝退 |

## 请假/断更管理

### 请假策略

| 情况 | 处理方式 | 说明 |
|------|----------|------|
| 临时有事 | 提前存稿顶替 | 不中断更新 |
| 身体不适 | 提前通知 + 补更承诺 | 读者理解度高 |
| 状态不佳 | 减少更新 + 调整 | 保证质量 |
| 重要事件 | 提前公告 + 存稿 | 婚丧嫁娶等 |

### 补更承诺

```
【请假条】
因 [原因]，今日请假一天
承诺：[补更时间/爆更补偿]
感谢理解！
```

## 写作计划

### 每日写作流程

| 时间 | 任务 | 说明 |
|------|------|------|
| 上午 | 构思大纲 | 梳理本章剧情 |
| 下午 | 写正文 | 2000-3000 字 |
| 晚上 | 自检 + 发布 | 质量检查，20:00 发布 |
| 睡前 | 看评论 | 回复读者，收集反馈 |

### 周写作计划

| 日期 | 更新计划 | 存稿目标 |
|------|----------|----------|
| 周一 | 1 章 | +1 章存稿 |
| 周二 | 1 章 | +1 章存稿 |
| 周三 | 1 章 | +1 章存稿 |
| 周四 | 1 章 | +1 章存稿 |
| 周五 | 1 章 | +1 章存稿 |
| 周六 | 2 章 | 0 存稿（周末爆更） |
| 周日 | 2 章 | -1 存稿 |

**周产出：9 章，存稿净变化：-1 章**

## 紧急预案

### 断更风险应对

| 风险 | 预案 |
|------|------|
| 突发断更 | 立即用存稿顶替 |
| 存稿不足 | 提前公告，请求理解 |
| 状态极差 | 发单章说明，调整 1-2 天 |
| 数据暴跌 | 检查毒点，快速调整剧情 |

### 负面反馈处理

| 情况 | 处理方式 |
|------|----------|
| 差评 | 分析原因，合理则改，不合理忽略 |
| 毒点举报 | 立即检查，确认则修改 |
| 恶意评论 | 拉黑 + 删除，不影响心态 |
| 剧情争议 | 作者说回应，坚持主线 |
