## 关系变化规则

### 关系类型

| 类型 | 说明 | 变化条件 |
|------|------|----------|
| 敌对 | 生死仇敌 | 一方死亡/和解 |
| 盟友 | 共同利益 | 利益冲突/背叛 |
| 中立 | 无直接关系 | 事件触发 |
| 附属 | 依附关系 | 实力变化 |

### 关系变化阶段

1. **初识** → 陌生/警惕
2. **接触** → 试探/利用
3. **合作** → 信任建立
4. **深化** → 生死之交/恋人
5. **变故** → 背叛/牺牲/升华
