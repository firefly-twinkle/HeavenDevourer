# 写作 Prompt 指南

---

## 使用说明

本目录包含所有写作相关的 Prompt 模板，用于指导 AI 生成符合要求的章节内容。

---

## 核心写作 Prompt

### 标准章节生成 Prompt

```
你是一名专业的玄幻小说作家，请根据以下信息生成第 X 章正文：

【章节信息】
- 章节编号：第 X 章
- 章节标题：[标题]
- 所属卷数：第 1 卷：血染青云
- 字数要求：2000-3000 字

【剧情要求】
1. 本章目标：[本章要完成的核心剧情]
2. 冲突来源：[至少 1 个冲突点]
3. 情绪基调：[爽/紧张/压迫/好奇等]
4. 悬念设置：[结尾钩子]

【设定约束】
- 主角当前修为：[武者 X 星]
- 不允许突破设定等级
- 不允许引入未定义角色
- 不允许使用英文（系统提示除外）
- 正文不允许使用 markdown 格式

【节奏要求】
- 每 1000 字至少 1 个冲突点
- 至少 3 个冲突节点
- 至少 1 个爽点
- 情绪有起伏

【输出格式】
第 X 章 [标题]

[正文内容，纯文本]

【本章总结】
- 推进点：
- 冲突：
- 情绪变化：
- 悬念：
```

## 大纲生成 Prompt

### 章节蓝图生成 Prompt

```
请为第 1 卷第 X-Y 章生成详细的章节蓝图：

【已知信息】
- 卷目标：[第 1 卷核心目标]
- 当前位置：主角刚 [上一个剧情节点]
- 下一个剧情节点：[目标事件]

【生成要求】
为每一章设计：
1. 章节标题（简洁有力）
2. 核心目标（本章要完成什么）
3. 主要冲突（至少 2 个）
4. 出场角色（不超过 3 个新角色）
5. 情绪基调（爽/紧张/压迫等）
6. 悬念设置（结尾钩子）
7. 爽点设计（如何打脸/突破/震惊）

【约束条件】
- 不允许跳过重要角色（内鬼林福、女主柳如烟）
- 不允许提前引入后续章节内容
- 严格遵循时间线（Day X）
- 符合修为等级设定

【输出格式】
### 第 X 章 [标题]
- 时间：Day X
- 地点：[地点]
- 核心目标：
- 主要冲突：
  1. 
  2. 
- 出场角色：
- 情绪基调：
- 爽点设计：
- 悬念结尾：
- 伏笔埋设：
```

## 内容优化 Prompt

### 章节润色 Prompt

```
请对以下章节内容进行优化：

【优化方向】
1. 冲突强化：冲突不够激烈，需要升级
2. 节奏调整：前期太慢，需要加快
3. 爽点增强：打脸不够爽，需要更强烈
4. 悬念优化：结尾不够吸引人
5. 逻辑检查：是否有不合理之处

【原文】
[粘贴章节内容]

【输出要求】
1. 保留核心剧情
2. 强化冲突描写
3. 增加心理活动
4. 优化对话节奏
5. 增强画面感

【约束】
- 字数保持在 2000-3000 字
- 不允许改变人物性格
- 不允许修改设定
- 保持纯文本格式
```

## 特殊场景 Prompt

### 战斗场景生成 Prompt

```
请生成一场战斗场景：

【战斗信息】
- 主角：林夜（武师 X 星）
- 敌人：[敌人信息，武者 Y 星]
- 地点：[战斗场地]
- 战斗类型：[碾压/苦战/智取]
- 情绪基调：[紧张/爽快/压迫]

【战斗要求】
1. 战斗过程要有层次感（试探→交锋→爆发→结局）
2. 要有招式描写（使用已掌握的武技）
3. 要有心理博弈
4. 要有环境描写
5. 要有围观者反应（如果有）

【武技使用】
- 主角已掌握：狮吼功（小成）、烈焰爪（大成）、开山掌（入门）
- 不允许使用未掌握的武技
- 可以展示新领悟的招式

【输出要求】
- 战斗字数：800-1500 字
- 纯文本格式
- 招式名称用引号标注
```

### 突破场景生成 Prompt

```
请生成一段突破场景：

【突破信息】
- 当前修为：武者 X 星
- 突破后：武者 Y 星 / 大境界突破
- 突破原因：[战斗突破/闭关突破/丹药辅助]
- 突破难度：[顺利/艰难/生死突破]

【描写要求】
1. 突破前的状态（灵力积蓄/瓶颈感受）
2. 突破过程（灵力涌动/经脉扩张）
3. 突破异象（光芒/气流/震动）
4. 突破后感受（力量增长/感官提升）
5. 旁人反应（如果有围观者）

【约束】
- 小境界突破：简单描写（200-300 字）
- 大境界突破：详细描写（500-800 字）
- 生死突破：重点描写（800-1000 字）
- 符合修炼等级设定
```

### 对话场景生成 Prompt

```
请生成一段对话场景：

【对话信息】
- 场景：[地点/情境]
- 参与角色：[角色 A、角色 B...]
- 对话目的：[传递信息/制造冲突/展现性格]
- 情绪基调：[轻松/紧张/严肃]

【角色性格】
- 林夜：冷静、果断、有仇必报
- [其他角色性格]

【对话要求】
1. 符合角色性格
2. 信息分阶段释放（不要一次性说完）
3. 要有潜台词
4. 要有动作/表情描写
5. 避免废话

【约束】
- 对话要简洁有力
- 每句话不超过 30 字
- 适当插入心理活动
```

## 伏笔管理 Prompt

### 伏笔埋设检查 Prompt

```
请检查以下章节内容是否包含伏笔：

【检查项目】
1. 是否有物品伏笔（玉佩/令牌/秘籍等）
2. 是否有人物伏笔（神秘人/身份异常等）
3. 是否有世界观伏笔（上古传说/势力关系等）
4. 是否有剧情伏笔（未来冲突/角色命运等）

【当前章节】
第 X 章：[标题]

【章节内容】
[粘贴内容]

【输出格式】
伏笔检查结果：
- 新增伏笔：[名称、类型、说明]
- 回收伏笔：[名称、对应埋点、回收方式]
- 建议补充：[可以在哪里增加伏笔]
```

## 质量检查 Prompt

### 章节质量自检 Prompt

```
请对以下章节进行质量检查：

【检查清单】
1. 冲突检查：是否至少 3 个冲突点
2. 爽点检查：是否至少 1 个爽点
3. 悬念检查：结尾是否有钩子
4. 设定检查：是否符合修为/世界观设定
5. 逻辑检查：是否有不合理之处
6. 格式检查：是否使用 markdown 格式
7. 英文检查：正文是否有英文
8. 字数检查：是否 2000-3000 字

【章节内容】
[粘贴内容]

【输出格式】
质量检查结果：
- ✅ 通过：[项目]
- ❌ 不通过：[项目 + 修改建议]
- ⚠️ 建议优化：[项目 + 优化方向]

综合评分：[X/10 分]
```

## 多章节连贯性检查 Prompt

```
请检查第 X-Y 章的连贯性：

【检查项目】
1. 时间线是否连续
2. 修为变化是否合理
3. 地点转换是否合理
4. 角色状态是否一致
5. 剧情是否连贯
6. 伏笔是否连续

【章节范围】
第 X 章 至 第 Y 章

【输出格式】
连贯性检查结果：
- ✅ 连续：[项目]
- ❌ 断裂：[项目 + 断裂点 + 修复建议]
- ⚠️ 建议：[改进方向]
```

## 使用说明

1. 复制对应 Prompt 模板
2. 替换【】中的变量
3. 发送给 AI 生成内容
4. 根据输出结果进行微调
