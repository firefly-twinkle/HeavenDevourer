## 冲突密度规则

### 基础规则

| 规则 | 标准 | 检查方式 |
|------|------|----------|
| 每 1000 字 | ≥1 个冲突点 | 写作时自我检查 |
| 每章（2000-3000 字） | ≥3 个冲突节点 | 写作后检查 |
| 禁止无冲突段落 | >300 字 | 阅读检查 |
| 禁止连续 2 章无冲突 | - | 章节间检查 |

### 冲突节点定义

**冲突节点** = 主角遇到阻碍/挑战/对抗的时刻

**包括**：
- ✅ 战斗/对决
- ✅ 言语冲突/挑衅
- ✅ 心理挣扎/抉择
- ✅ 环境阻碍/危险
- ✅ 时间压力/倒计时
- ✅ 信息不对称/误解
- ✅ 资源争夺/竞争

**不包括**：
- ❌ 纯对话（无冲突）
- ❌ 纯描述（无阻碍）
- ❌ 纯回忆（无当下冲突）

## 冲突节奏（强制）

### 基础节奏
- 每 3 章一个小冲突升级
- 每 5 章一个大爽点
- 每 10 章一个爆点
- 每卷至少一个 L5 级冲突

### 压强递增规则
| 章节范围 | 压强等级 | 说明 |
|----------|----------|------|
| 第 1-5 章 | L2→L3 | 穿越→逃亡→成长 |
| 第 6-15 章 | L3→L4 | 狩猎→返回→擂台 |
| 第 16-25 章 | L4→L5 | 连胜→暴露→围剿 |
| 第 26-35 章 | L3→L4 | 营救→复仇→突破 |
| 第 36-45 章 | L4→L5 | 围剿→绝境→爆发 |
| 第 46-50 章 | L5 | 卷末高潮 |

### 情绪循环
```
轻 (过渡) → 压 (冲突) → 爽 (反击) → 爆 (高潮) → 缓 (消化)
```
- 循环周期：3-5 章
- 禁止连续 2 章处于同一情绪状态
- 每卷至少完成 3 个完整循环

### 冲突设计技巧

#### 1. 冲突叠加
```
外部冲突（敌人追杀）+ 内部冲突（时间压力）= 紧张感翻倍
```
**示例**：第 25 章：青云子围剿（外部）+ 莫老下落不明（内部）+ 时间压力（快逃）

#### 2. 冲突升级
```
小冲突 → 中冲突 → 大冲突 → 生死冲突
```
**示例**：第 16-18 章：连胜（小）→ 金甲战神（中）→ 白长老（大）→ 十连胜完成（生死）

#### 3. 冲突转换
```
一个冲突解决 → 新冲突出现 = 剧情持续推进
```
**示例**：第 25 章：夺得令牌（解决）→ 被围剿（新冲突）→ 逃脱（解决）→ 莫老下落不明（新冲突）

#### 4. 冲突对比
```
极度危险后短暂平静 = 读者情绪缓冲
```
**示例**：第 25 章末：逃脱后→山洞疗伤（第 26 章开场）

## 冲突检查清单

### 写作前
- [ ] 本章计划几个冲突节点？（至少 3 个）
- [ ] 冲突类型是什么？（人 vs 人/组织/自然）
- [ ] 冲突等级是什么？（L1-L5）

### 写作中
- [ ] 有超过 300 字的无冲突段落吗？
- [ ] 冲突节点之间有连接吗？
- [ ] 冲突有升级吗？

### 写作后
- [ ] 冲突节点数≥3 个吗？
- [ ] 有推进剧情吗？
- [ ] 与前一章冲突类型重复吗？
